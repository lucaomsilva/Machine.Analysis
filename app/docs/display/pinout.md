### Pinout Configuration (ESP32-S3 <-> ST7796S)

| Display Pin | ESP32-S3 GPIO | Description |
| :---------- | :------------ | :---------- |
| VCC         | 3.3V          | Power       |
| GND         | GND           | Ground      |
| CS          | 10            | Chip Select |
| RST         | 9             | Reset       |
| DC          | 8             | Data        |
| MOSI        | 11            | SPI Data    |
| SCK         | 12            | SPI Clock   |
| MISO        | 13            | SPI Input   |
| LED         | 4             | Backlight   |
